# Datenschutzerklärung Jarvis

Jarvis wird privat betrieben und nur vom Betreiber selbst genutzt.

- **Zugriff:** Google Kalender (lesen und schreiben), Drive, Kontakte und Aufgaben (lesen), E-Mail-Adresse und Profil. Gmail wird von Jarvis nicht genutzt.
- **Zweck:** ausschliesslich die persönliche Assistenz des Kontoinhabers.
- **Speicherung:** Zugangsdaten und abgerufene Daten liegen auf einem privaten Server des Betreibers.
- **Lokale Verarbeitung:** Normale Anfragen, Drive-Suche und Drive-Zusammenfassungen werden mit einem lokalen Sprachmodell auf diesem Server verarbeitet.
- **Weitergabe:** Termine werden dem Betreiber über Telegram zugestellt. Nur wenn der Betreiber ausdrücklich den Befehl /claude verwendet, gehen die Nachricht, der jüngste Chatverlauf, die Kalendertermine der nächsten 7 Tage, offene Erinnerungen und eine Wetterzusammenfassung an Anthropic, damit Claude antworten kann. Drive-Inhalte werden nie an Anthropic übermittelt. Es gibt keinen Verkauf, keine Werbung und kein Training von KI-Modellen durch Jarvis.
- **Limited Use:** Die Nutzung von Daten aus Google-APIs richtet sich nach der [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy) einschliesslich der Limited-Use-Anforderungen.
- **Widerruf:** jederzeit unter [myaccount.google.com/permissions](https://myaccount.google.com/permissions)
- **Kontakt:** [GitHub: AIhdproduction](https://github.com/AIhdproduction)
